# PyTrading
Python Based System  which back test trading strategies.
The application "PyTrading" is for predicting the dynamic changes to stock prices. Here, we will use the dynamic ML model for predicting the price, and predicting the highest stock price for your trade. 
The name iteself says that this application is for traders, stock marketers, and finance people. 
PyTrading - Python + Trading and the application is usually for people to reduce some manual work or monitoring work and providing the accurate trading outcome. 

Key Features:
-> Python Backtesting 
-> Algorithmic Trading 
-> Automation of different Trading Strategies 
-> Using Dynamic Machine Learning Model, we will provide the desired and accurate outcomes 

What kind of traders, we are targeting:
- Interactive Brokers Trader
- Pattern Day Traders
- Common Retail Intraday Traders
- Retail Algorithmic Trading
